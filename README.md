# starplotTirion
Repository for my work to use Steve Berardi's starplot (https://github.com/steveberardi/starplot) to create Tirion/PocketSkyAtlas styled maps.

### Project Motivation: 

**[5 Oct 2026]** In 2001, I wrote a small handbook with Telrad finder charts called the **SMAS 50**. I've often thought about revising it, and in particular in making new similar charts -- I find them useful for teaching, public talks, and so on. I made that first **SMAS 50** book by making charts using the old Macintosh version of *The Sky* by Software Bisque. Software I've had since then (notably *Starry Night* which seems to have not been updated in many years now) has failed to make the nice charts of that old version -- what I call "Tirion Style," after Wil Tirion (of *Cambridge Star Atlas*, *Sky Atlas 2000*, and *Uranometria* fame). The modern ***Pocket Sky Atlas*** has the same aesthetic, defined by the clear focus on naked-eye (or nearly) stars for limiting magnitude, and the classic symbols used by Tirion for deep sky objects (which I've grown used to after many decades of observing!).

So since I made the original **SMAS 50**, I've kept my old blue-and-white Power Macintosh G3, so I could once again fire up *The Sky* and make some new charts. So this weekend, after a 25-year hiatus, I set up that old G3. I remembered my login and password! And to my shock and dismay, *the software was not installed on the machine!* Even more distressing, I had a shelf of all my old software CDs in the house in Illinois, and when we moved here to New York last year, *I have no idea where they ended up!* 

When I was working on this 25 years ago, I did not have any easy way to generate my own graphic output, but realized that today python plotting made it possible I could probably from a database of stars (like Hoffleit's *Yale Bright Star Catalog*) just make my own charts. But then I was like "someone *must* have trying to make python star charting software!" And they have!

I found the **starplot** python library by Steve Berardi! This notebook is to develop my use of **starplot** in my quest to make the Telrad charts I'm after!
